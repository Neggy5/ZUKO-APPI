Developer quick start

Use ZUKO API in minutes.

Every /v1/ endpoint uses your API key. Copy one of the examples below and plug it into a bot, website, mobile app, backend, Python script, or any HTTP client.

Get an API keyQuick start

How to call the API

1. Create your accountRegister in the developer console and verify your email if verification is enabled.
2. Create an API keyOpen the console, create a key and keep it private. Do not put it in frontend JavaScript.
3. Add the keyUse Authorization: Bearer YOUR_API_KEY or x-api-key.
4. Call an endpointUse the exact method and route shown below. GET parameters go in the URL; POST data goes in JSON.

Base URL

BASE_URL = window.location.origin
When your API is deployed on Railway, this becomes your public Railway URL.

Copy-and-use examples

cURL

curl -X GET "https://YOUR-API-DOMAIN.up.railway.app/v1/tools/uuid" \
  -H "Authorization: Bearer YOUR_API_KEY"

Node.js / JavaScript

const BASE_URL = 'https://YOUR-API-DOMAIN.up.railway.app';
const API_KEY = process.env.ZUKO_API_KEY;

const res = await fetch(`${BASE_URL}/v1/tools/uuid`, {
  headers: { Authorization: `Bearer ${API_KEY}` }
});

const data = await res.json();
console.log(data);

Python

import os, requests

url = 'https://YOUR-API-DOMAIN.up.railway.app/v1/tools/uuid'
headers = {'Authorization': f"Bearer {os.environ['ZUKO_API_KEY']}"}

response = requests.get(url, headers=headers, timeout=30)
print(response.json())

PHP

$url = 'https://YOUR-API-DOMAIN.up.railway.app/v1/tools/uuid';
$ch = curl_init($url);
curl_setopt_array($ch, [
  CURLOPT_RETURNTRANSFER => true,
  CURLOPT_HTTPHEADER => ['Authorization: Bearer ' . getenv('ZUKO_API_KEY')]
]);
echo curl_exec($ch);

Bot example — WhatsApp / Baileys

Your bot can call ZUKO exactly like any other HTTPS API. Keep the API key in an environment variable.

const ZUKO_API = 'https://YOUR-API-DOMAIN.up.railway.app';
const ZUKO_KEY = process.env.ZUKO_API_KEY;

async function zuko(path, options = {}) {
  const response = await fetch(`${ZUKO_API}${path}`, {
    ...options,
    headers: {
      Authorization: `Bearer ${ZUKO_KEY}`,
      'Content-Type': 'application/json',
      ...(options.headers || {})
    }
  });
  return response.json();
}

// Example inside a bot command:
const result = await zuko('/v1/tools/uuid');
await sock.sendMessage(from, { text: `UUID: ${result.uuid}` });
Never paste a private API key directly into a public GitHub repository, browser frontend, or shared bot source. Store it as an environment variable such as ZUKO_API_KEY.

Built-in endpoints

Build your own endpoint

Create a JavaScript module under api/endpoints/. ZUKO discovers endpoint modules automatically when the server starts.

api/endpoints/tools/hello.js

module.exports = {
  name: 'Hello',
  method: 'GET',
  path: '/v1/tools/hello',
  category: 'Tools',
  description: 'Return a greeting.',

  async execute({ query, ctx }) {
    const name = ctx.cleanString(query.name || 'Developer', 80);
    return { status: true, message: `Hello ${name} 👋` };
  }
};

Platform features such as API-key authentication, quotas, rate limits and usage logging are handled automatically for /v1/ routes.
