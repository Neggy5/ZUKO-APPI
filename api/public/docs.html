Adding your next endpoint

Create a provider/helper, add one authenticated route under /v1, validate inputs, and use sendResult(). That automatically participates in API-key quotas and request logging.

app.get(`${API_PREFIX}/tools/example`, async (req, res, next) => {
  const started = Date.now();
  try {
    const q = cleanString(req.query.q, 300);
    if (!q) return sendResult(res, req, started, 400,
      { status:false, error:'q is required' });
    const result = await getExample(q);
    return sendResult(res, req, started, 200,
      { status:true, result });
  } catch (err) { next(err); }
});
